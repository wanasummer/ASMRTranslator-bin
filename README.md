## 它能做什么

你只需要提供两样东西：

1. **原始 ASMR 音频**（MP3 / WAV 等格式）
2. **对应的中文字幕文件**（VTT / SRT / LRC 均可）

软件会按字幕的时间轴把音频切成一句句，用你选定的中文 TTS 引擎逐句朗读翻译文本，再做音量对齐、声音处理，最后拼接成完整的中文配音音频（输出 MP3 和 WAV 两种格式）。

---

## 核心特色

- **全流程自动化**：选好文件 → 点一下开始，解析字幕、切割音频、逐句配音、声音处理、拼接导出全自动完成，实时显示进度。
- **多 TTS 引擎**：内置微软 Edge TTS（免费）、小米 MiMo TTS、Fish Audio 三个引擎，覆盖免费到高端的音色需求。
- **说话人自动匹配音色**：字幕里标注了「遥：」「瑠衣：」等说话人时，自动为每个角色分配不同音色。
- **智能响度对齐**：每句中文配音自动对齐到原声段落的音量，避免忽大忽小。
- **并行加速**：音频切割、TTS 请求、音频合成多线程并行，充分利用多核 CPU。
- **断点缓存**：改个语速/音量重跑时，已生成的片段自动跳过，秒级重出。
- **单文件便携版**：打包为单个 EXE，双击即用，无需安装 Python / ffmpeg / Node。
- **界面全中文**，四步向导式操作，配有实时运行日志。

## 四种听音模式

| 模式 | 效果 | 适合场景 |
| --- | --- | --- |
| **替换模式**（默认） | 日文原声完全替换为中文配音，得到纯中文 ASMR | 想要干净、随时可听的中文版 |
| **保留原声 · 对照** | 每句先放日文原声，停顿后再放中文翻译，一句一句对照 | 学日语 / 学中文的对照学习 |
| **声音同步** | 中文翻译与日文原声同时叠加输出，可选「跟随原声」或「跟随翻译」对齐策略 | 跟原声节奏贴合的沉浸式体验 |
| **潜意识同传** ⭐ | 日文原声 100% 无损保留，中文被处理成低音量、延迟、带混响的「脑内回响」 | 完整享受原声的同时隐隐听懂在说什么，非常适合助眠 |

## 使用方法

1. **选择文件**：点击「浏览」选择 ASMR 音频文件和中文字幕文件（VTT / SRT / LRC）。
2. **参数设置**：选择 TTS 引擎、听音模式，调节语速、音量、交叉淡化等参数。
3. **开始转换**：点击「开始转换」，实时查看进度条与运行日志。
4. **输出结果**：完成后直接给出 MP3 与 WAV 文件，一键「打开」。

> 所有配置会自动保存（写入用户主目录下的 `.asmrts` 文件），下次启动自动恢复。

## 常见问题

**Q1：Edge TTS 需要注册或付费吗？**
不需要。Edge TTS 是微软在线语音服务，免费、无需任何 Key，联网即用。

**Q2：为什么选择「保留原声 / 声音同步」后中文没有声音？**
请检查「翻译音量」是否被调到了 0%。另外声音同步模式下中文与原声叠加，响度是相加的，如果觉得太响可以适当调低翻译音量。

**Q3：字幕里没有说话人标注，音色怎么分配？**
会统一使用「自动匹配」默认音色。建议在字幕里把说话人写成 `名字：内容` 格式，就能逐角色分配音色。

**Q4：输出有哪些文件？**
MP3（192kbps）和 WAV 两种格式，方便直接播放或用剪辑软件进一步加工。

**Q5：潜意识同传和声音同步有什么区别？**
声音同步是中文与原声同时、等音量叠加（原声被覆盖一部分）；潜意识同传则是原声 100% 无损，中文被处理成低音量、延迟、带混响的「脑内回响」，几乎不打扰原声。
